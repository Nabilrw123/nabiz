# Nabiz Orchard Intelligence

Dashboard web statis untuk memonitor kebun mangga dengan visualisasi sensor lingkungan, peta blok kebun interaktif, dan modul deteksi kematangan buah berbasis analisis gambar.

## Fitur utama
- **Ringkasan lingkungan**: kartu metrik untuk suhu udara, kelembapan udara, kelembapan tanah, dan suhu tanah dengan pembaruan berkala.
- **Grafik tren**: kanvas interaktif yang menggambarkan evolusi suhu/kelembapan udara dan kelembapan tanah.
- **Peta kebun**: grid blok kebun dengan status kesehatan yang dapat diklik untuk melihat detail varietas serta kondisi setiap blok.
- **Deteksi kematangan**: unggah foto mangga untuk menganalisis tingkat kematangan berdasarkan dominasi warna dan luminansi.
- **Rekomendasi operasional**: saran tindak lanjut berdasarkan kondisi sensor dan prediksi visi komputer.

## Cara menjalankan
Buka berkas `index.html` di peramban modern. Semua dependensi berada dalam proyek sehingga dapat berjalan secara offline.
